# ✿ maki 的工作台

一款专门用来收集 OC 角色设定、PARO、约稿过程与灵感随记的私人网页，手机与电脑均可使用。没有登录系统，也不需要付费数据库。

## 网页里有什么？

- **工作台**：首页髭切中日台词淡入淡出轮播（可手动切语言、上下句、暂停，设置里自行编辑中日对照台词）、四个板块的记录数量、最近修改、未完成约稿的预计完成日期。
- **OC 设定**：角色名称、立绘封面、年龄、生日、代称、外貌、性格、背景故事、世界线/AU、自定义字段、图像画廊、搜索/排序、卡片/列表/表格切换，以及旧版设定恢复；设定可一键复制。
- **PARO 记录**：标题、主题、世界观、登场角色、正文，一键复制。
- **约稿存档**：作品信息、下单/预定/实际完成日期、金额（可选）、画面需求、每一版草稿和高清成图（可排序）、过程备注、画作小故事；点击图片可放大和下载原始文件。
- **灵感随记**：标题、类别、自由记录，一键复制。
- **个性化**：自定义网站名称、用户头像、五套和式配色 + 自选主题色、浅色/深色模式、四种系统字体风格、简体/繁体中文界面。
- **完整备份**：导出 ZIP（包含全部文字和原始图片），以及使用 ZIP 导入恢复。

## 最简单的使用方式：免费发布为网址

建议使用 GitHub Pages、Cloudflare Pages 或其他支持 HTTPS 的静态网站托管平台。它们不需要后端，适合这个网页。

### 使用 GitHub Pages（示例）

1. 解压 `maki-workbench.zip`，得到 `index.html`、`app.js`、`styles.css`、`sw.js`、`manifest.webmanifest` 和 `assets` 文件夹。
2. 在 GitHub 新建仓库，上传这些文件到仓库根目录（保持文件夹结构）。
3. 到仓库 **Settings → Pages → Build and deployment**，选择 **Deploy from a branch**，选择 `main` / `/(root)`，保存。
4. GitHub Pages 生成一个公开 HTTPS 网址后，将网址发给朋友，手机和电脑浏览器都可以打开。
5. 第一次打开后，浏览器会缓存网页资源。安装缓存成功的情况下，之后断网也可打开网页并编辑本地资料（受浏览器离线缓存保留情况影响）。

这里提供的是**可部署的网站源文件**，并没有替你创建 GitHub 仓库或上线公开网址。

## 本地电脑上预览

不要只双击 `index.html`：一些浏览器在 `file://` 下会限制 IndexedDB 或离线功能。

如电脑装有 Python，可在解压后的目录运行：

```bash
python -m http.server 8000
```

然后打开：`http://localhost:8000`。访问成功后即可创建并保存内容。**正式使用仍建议部署到 HTTPS 网址**。

## 重要：资料到底存在哪里？

**数据只保存在当前设备当前浏览器的网站数据中（IndexedDB）**，没有上传到服务器：

- 同一个网址在手机和电脑上打开，它们的资料是**彼此独立的**，不会自动同步。
- 要把手机的资料转到电脑：先在手机打开 **设置 → 导出完整备份**，把 ZIP 文件传到电脑，再在电脑打开 **设置 → 导入备份**。
- **导入会完全覆盖目标设备当前的工作台资料**，导入前请先导出旧备份。
- 清除网站数据、使用无痕模式、某些浏览器自动清理存储，或换设备，都可能导致本地资料丢失。
- 请定期保存 ZIP 备份到独立文件夹/网盘，尤其是在上传较多高清约稿原图后。
- 高分辨率原图可能占用较大空间，浏览器的可用存储配额因设备和浏览器而异。
- 网址可以公开，但**每位访问者只能看到自己当前浏览器里保存的资料**；如果其他人使用了朋友的同一台设备和相同浏览器配置，他们仍可访问该设备的资料。此方案**不是密码保护**。

## 技术说明

- 纯 HTML + CSS + JavaScript，**无第三方依赖、无服务器端程序、无 API Key**。
- IndexedDB 存文字和原始图片；为显示性能另外生成较小的缩略图（不修改原图）。
- ZIP 备份采用标准**不压缩（STORE）** ZIP 格式，画质完全保留，文件可能比较大。
- 备份只支持导入**由本网站生成的 ZIP**；不支持随意压缩的文件夹，也不支持加密压缩包。
- PWA 离线缓存需要 HTTPS 或 localhost，并以浏览器兼容性为准。
- 简繁切换仅影响网站界面，**不会自动翻译用户自己的 OC 文字**。四套字体使用设备现有字体，实际效果会因手机系统不同而略有差异。

## 首页髭切中日台词轮播

首页原来的欢迎标语现在改为「髭切 · 台词收藏」：点击 **中文 / 日本語** 可切换当前语句语言，箭头可以换上一句或下一句，播放按钮可以暂停动画；开启自动轮播时默认每约 5.8 秒切换一次语言或下一句。系统开启“减少动态效果”时不自动播放。

**请注意：自带的三组句子是原创演示文案，并非《刀剑乱舞》官方台词。** 进入 **偏好设置 → 髭切 · 中日台词**，可以逐组改成你自己收藏的官方台词、添加或删除台词组合。输入框失焦后保存，所有台词包含在 ZIP 完整备份里。

更新已有网站：先导出旧版完整备份，将新的 `index.html`、`app.js`、`styles.css`、`sw.js` 及其余文件上传覆盖原网页；**不要清除浏览器的网站数据**，即可保留原来的 OC、图片和约稿资料。
